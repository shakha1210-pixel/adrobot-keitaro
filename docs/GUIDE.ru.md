# Руководство пользователя

> Цель: запустить Adrobot и выполнить повседневные задачи без необходимости разбираться во внутренней архитектуре.

## 1. Что такое Adrobot

Adrobot — веб-интерфейс над Keitaro Admin API. Он помогает создавать кампании по заданному шаблону и редактировать офферы в существующих потоках. Данные кампаний и офферов остаются в Keitaro; локальная база Adrobot используется для журнала операций.

## 2. Запуск за несколько минут

### Windows (PowerShell)

```powershell
git clone https://github.com/shakha1210-pixel/adrobot-keitaro.git
cd adrobot-keitaro
.\scripts\dev.ps1
```

При первом запуске скрипт создаст виртуальное окружение, установит зависимости, скопирует `.env.example` в `.env` и применит миграции. Откройте `.env`, заполните `KEITARO_API_KEY`, проверьте `CAMPAIGN_PREFIX`, `DEFAULT_DOMAIN`, `DEFAULT_GROUP` и `DEFAULT_SOURCE`, затем запустите скрипт ещё раз.

### Linux / macOS

```bash
git clone https://github.com/shakha1210-pixel/adrobot-keitaro.git
cd adrobot-keitaro
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-dev.txt
cp .env.example .env
# Заполните .env, затем:
alembic upgrade head
uvicorn app.main:app --reload
```

Откройте:
- Интерфейс: http://127.0.0.1:8000
- Проверка API: http://127.0.0.1:8000/docs
- Сводный статус: http://127.0.0.1:8000/health

## 3. Создание кампании

1. Откройте вкладку **Новая кампания**.
2. Введите название, начинающееся с обязательного префикса из `.env` (например, `test_familiya_`).
3. Выберите двухбуквенный ISO-код страны.
4. Найдите и выберите существующий offer.
5. Отправьте форму и дождитесь результата.

Сервис создаёт два потока: первый направляет выбранное GEO на `REDIRECT_URL`, второй служит catch-all и отправляет трафик на выбранный offer с долей 100%. Успех показывается только после чтения и проверки созданной конфигурации.

**Важно:** если запрос завершился неоднозначной сетевой ошибкой, не нажимайте «создать» повторно сразу. Сначала проверьте кампанию в Keitaro: сервер мог принять запрос, но ответ не дошёл до приложения.

## 4. Редактирование кампании

1. Перейдите в **Редактор кампаний**.
2. Найдите кампанию по названию, префиксу или ID.
3. Откройте нужный поток.
4. Добавьте offer или удалите один из существующих.
5. Проверьте доли: сумма должна составлять 100%.

Последний offer в потоке удалить нельзя — пустой поток не допускается. При изменении списка офферов Adrobot старается сохранить остальные поля конфигурации потока.

## 5. История операций

Вкладка **История операций** показывает зарегистрированные действия, их результат и время. Это журнал приложения, а не полноценный журнал действий пользователей: авторизация и идентификация отдельных операторов не реализованы.

## 6. Если что-то пошло не так

| Что видите | Что сделать |
|---|---|
| Ключ не задан | Заполните `KEITARO_API_KEY` в `.env` и перезапустите сервер |
| Ошибка конфигурации | Сверьте домен, группу и источник с именами в Keitaro |
| `/health/ready` вернул 503 | Проверьте доступность БД и Keitaro |
| `keitaro_ambiguous` | Не повторяйте мутацию вслепую; сначала проверьте результат в Keitaro |
| Не находится offer | Убедитесь, что offer существует и доступен API-ключу |

Пошаговая диагностика, команды для просмотра логов и шаблон обращения за помощью: [Техническая поддержка и логи](OPERATIONS.ru.md).
